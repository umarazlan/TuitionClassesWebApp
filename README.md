# 🎓 Tuition Classes Web App

A modern and responsive Tuition Classes website built using React and Vite.  
This project showcases a clean UI for tuition academy services including courses, qualifications, fee structure, contact section, and more.

---

## 🚀 Features

- Responsive Design
- Modern UI/UX
- Hero Section
- About Section
- Qualifications Section
- Fee Structure
- Services Section
- Contact Form
- Scroll To Top Button
- Error Page
- Fast Performance with Vite

---

## 🛠️ Tech Stack

- React.js
- Vite
- JavaScript
- CSS3
- HTML5

## ⚡ Installation

Clone the repository:

```bash
git clone https://github.com/umarazlan/TuitionClassesWebApp.git
```

Go to project folder:

```bash
cd TuitionClassesWebApp
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```
